# Visualizer

A browser-based visualizer built with **HTML, CSS, and JavaScript**.

The project is currently in early development and is intended to provide an interactive interface for visualizing files, a tree structure, and a terminal.

## Features

* Tree visualizer
* File Preview and Editor
* Terminal
* Resizable panels
* Custom browser-based UI

## Tech Stack

* HTML
* CSS
* JavaScript

## Project Status

**In development**

The layout and core interface are currently being implemented. More functionality will be added over time.

## Running Locally

Clone the repository:

```bash
git clone <repository-url>
cd <repository-directory>
```

Then open the project in a browser, or use a local development server such as **VS Code Live Server**.
